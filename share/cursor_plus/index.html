【2025最新】5分钟订阅和升级Cursor Pro

  • emmm，当我正高高兴兴地在 vscode 中用 Cursor 写代码，突然发现屏幕上弹出了一个提示：“the model The model cursor-small does not work with your current plan or API key”
  • 后来我发现原来是之前我使用的是 cursor体验版 ，现在要升级到 cursor pro 才能继续使用。离谱！

没办法，我只能去找下有没有啥能够订阅cursor pro的方法。

还好，后来我还是找到了一个不错的解决方案：WildCard虚拟信用卡。体验还算不错吧

分享下教程吧～

  • 首先点击链接进入：WildCard 一分钟开卡，轻松订阅海外软件服务

  • 选择虚拟服务卡服务，注册完成后，选择卡片开通的时长（根据个人需要选择，个人推荐两年的，比较划算）。（PS：使用邀请码 I1QPSWPD 可以在开卡时优惠2美元。）

  • 支付并激活卡片，几分钟后，虚拟卡就成功开通了。进入“我的卡片”页面，就能看到卡号、安全码等信息。

  • 在开通成功后，咱们需要提前往卡里面充值一些金额，用来后续订阅Cursor Pro。

如何订阅升级Cursor Pro Plus

  • 点击 Cursor Pricing 查看Cursor的订阅策略界面，点击对应版本的Get Started按钮
    (PS: 一般 Pro就够用了)

  • 进入付款页面,这个页面需要填写一些刚才在 wildcard 申请的虚拟信用卡信息:

  • 进入 wildcard，选择需要支付的产品为 Cursor:

  • 然后选择你需要充值的金额（>= 你订阅的产品金额即可），充值完后，就会显示填写的信息,把这些信息复制到 Cursor 支付页面即可

  • 如果填完银行卡信息，还让你填个手机号的话，随便填一个合法的美国手机号即可，不需要真实的~.


    这就算是搞定啦～！！！
